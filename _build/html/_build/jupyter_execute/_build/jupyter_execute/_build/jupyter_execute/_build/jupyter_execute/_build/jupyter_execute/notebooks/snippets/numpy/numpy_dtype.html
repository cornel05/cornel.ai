Numpy Dtype Construction#

Array-scalar types#

>>> import numpy as np
>>> dt = np.dtype(np.int32) # 32-bit integer
>>> dt = np.dtype(np.complex128) # 128-bit complex floating-point number

Built-in types#

Several Python types are equivalent to a corresponding array scalar when used to generate a dtype object:

>>> import numpy as np
>>> dt = np.dtype(float) # Python-compatible float
>>> dt = np.dtype(complex) # Python-compatible complex
>>> dt = np.dtype(int) # Python-compatible integer
>>> dt = np.dtype(object) # Python-compatible object

Array-protocol type strings#

The first character specifies the kind of data and the remaining characters specify the number of bytes per item, except for Unicode, where it is interpreted as the number of characters. The item size must correspond to an existing type, or an error will be raised. The supported kinds are:

>>> import numpy as np

>>> np.dtype('i4') # 32-bit integer
>>> np.dtype('f8') # 64-bit floating-point number
>>> np.dtype('c16') # 128-bit complext floating-point number
>>> np.dtype('S25') # (not recommended) 25-length zero-terminated bytes
>>> np.dtype('U25') # 25-character Unicode string

Strings with comma-separated fields#

A short-hand notation for specifying the format of a structured data type is a comma-separated string of basic formats.

A basic format in this context is an optional shape specifier followed by an array-protocol type string. Parenthesis are required on the shape if it has more than one dimension.

  • field named f0 containing a 32-bit integer

  • field named f1 containing a 2 x 3 sub-array of 64-bit floating-point numbers

  • field named f2 containing a 32-bit floating-point number

>>> import numpy as np
>>> dt = np.dtype("i4, (2,3)f8, f4") # structured data type

  • field named f0 containing a 3-character string

  • field named f1 containing a sub-array of shape (3,) containing 64-bit unsigned integers

  • field named f2 containing a 3 x 4 sub-array containing 10-character strings

>>> import numpy as np
>>> dt = np.dtype("U3, 3u8, (3,4)U10") # structured data type

Type Strings#

>>> import numpy as np
>>> dt = np.dtype('uint8') # 8-bit unsigned integer
>>> dt = np.dtype('int16') # 16-bit integer
>>> dt = np.dtype('float32') # 32-bit floating-point number
